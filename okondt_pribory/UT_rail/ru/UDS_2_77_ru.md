# UDS2-77 AREMA — ультразвуковой однорельсовый дефектоскоп

## Основные особенности дефектоскопа

- Масса всего 17 кг для UDS2-77 AREMA с блоком скользящих преобразователей (SL) и 23 кг для UDS2-77 AREMA с колёсным иммерсионным блоком (RSUI). Такая масса достигнута за счёт лёгкого ударопрочного пластика.
- Режим стоянки дефектоскопа.
- Модульная конструкция: рама на роликах, центральный электронный блок, блоки мультиплексоров, аккумуляторная батарея, бак, система подачи контактной жидкости, блоки преобразователей, энкодер.
- Все модули легко собираются и разбираются и надёжно крепятся на раме дефектоскопа.
- Положение блока преобразователей регулируется в поперечной плоскости рельса.
- Адаптивные ролики центрируют блоки преобразователей по оси рельса.
- Подвеска блоков преобразователей сохраняет стабильный акустический контакт при боковом наклоне тележки до ±15° (для UDS2-77 AREMA (SL)).

## Основные технические характеристики

Ультразвуковой дефектоскоп UDS2-77 предназначен для сплошного контроля рельсов и стрелочных переводов, а также для подтверждающего контроля по результатам систем скоростного контроля. Дефектоскоп выявляет дефекты во всём сечении рельса, кроме перьев подошвы.

| Параметр | Значение |
|---|---|
| Соответствие | контроль рельсов по требованиям AREMA |
| Число каналов контроля (преобразователей) | 11 |
| Типы и частоты преобразователей | 0°/4 МГц; ±70°, ±40°/45°, ±50° (SL)/2 МГц |
| Шаг сканирования | 1 мм при скорости 4 км/ч |
| Режимы отображения | A-скан, B-скан, A-скан + B-скан |
| Регистрация | непрерывная запись результатов в формате базы данных с привязкой к путевой координате и координатам GPS |
| Просмотр | режим просмотра результатов на экране дефектоскопа |
| Масса без контактной жидкости | не более 17 кг (SL) и 23 кг (RSUI) |
| Объём бака для контактной жидкости | 5 л |
| Расход контактной жидкости | до 1,5 л/км при скорости 4 км/ч |

## Блоки преобразователей

На иллюстрациях брошюры:
- **UDS2-77 AREMA (SL)** — блоки скользящих преобразователей. Подписи: твердосплавные вставки, крышка, ползун (полиамид), рама, кабель.
- **UDS2-77 AREMA (RSU)** — колёсный преобразователь.

На иллюстрациях брошюры показаны:
- общий интерфейс дефектоскопа;
- режим отображения B-скана для одного канала;

- режим отображения A-скан + B-скан для одного канала.

## ПО для анализа и оценки результатов контроля

Программа **Rail Inspector** предназначена для отображения, анализа и оценки результатов контроля на ПК. В ней есть все необходимые инструменты для обработки данных.

Основные преимущества программы:
- удобная работа с базой данных проконтролированных участков (этапов);
- выбор схемы каналов контроля, контролируемого рельса, участка рельса и метода контроля;
- измерение условных размеров дефектов в режиме B-скана;
- просмотр A-скана по данным, записанным в B-скане;
- просмотр дефектограммы (B-скана) в режиме прокрутки или с быстрым переходом к заданной координате;
- режим путевой разметки для отметки подозрительных участков пути при просмотре результатов;
- сортировка результатов по уровню чувствительности от −6 до +6 дБ относительно уровня измерительного строба;
- режим просмотра и формирования отчётов по проконтролированному участку;
- режим просмотра протоколов подтверждающего контроля.
